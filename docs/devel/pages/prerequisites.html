Knowledge

The course is intended for those who have basic familiarity with Unix and the R scripting language.

We will also assume that you are familiar with mapping and analyzing bulk RNA-seq data as well as with the commonly available computational tools.

  • If a refresher is needed for Unix command line (hopefully not), please go over this tutorial and its companion cheatsheet.
  • Getting down to basics: an introduction to the fundamentals of R (courtesy of Mark Ravinet).
  • Gentle introduction to R/Bioconductor: here
  • For a full in-depth guide of Bioconductor ecosystem: read the comprehensive R/Bioconductor book from Kasper D. Hansen, freely available under the CC BY-NC-SA 4.0 license here.
  • The reference book for single-cell analysis with Bioconductor: Orchestrating Single-Cell Analysis with Bioconductor (OSCA).

Local configuration

Everything will be performed in the cloud, on the Orchestra platform (see Getting started). You will only need:

  • A computer with a high-speed internet access and an up-to-date web browser (Chrome, Firefox, Safari or Edge);
  • A Google account (personal or institutional), to sign in to the Orchestra platform;
  • The Zoom visioconference software.

Optionally, if you wish to run the labs on your own computer after the workshop, you will need to install Docker (with at least 8 GB of RAM available to it).

Remote configuration

The workshop sessions run from the Docker image built from this book (ghcr.io/js2264/scrnaseqphysalia2026). This image is built automatically by GitHub Actions every time the book is updated, from the Dockerfile stored in the book repository. It is based on the official bioconductor/bioconductor_docker image, and it provides:

  • R, Bioconductor and RStudio Server;
  • all the R packages used in the labs (listed in the DESCRIPTION file of the book);
  • the command-line tools used in the labs (seqkit, samtools, fastqc, ffq, listed in inst/requirements.yml);
  • the datasets used in the R labs, already downloaded and cached.

The exact version of every package installed in the image is listed in the “Session info” section of the Welcome page.
